# Phase 1.2 starter corpus

This release expands the local corpus for application testing. It contains selected canonical passages rather than complete works.

## Included works

- MN 10 — Satipaṭṭhāna Sutta
- MN 21 — Kakacūpama Sutta
- MN 22 — Alagaddūpama Sutta
- SN 56.11 — Dhammacakkappavattana Sutta
- SN 22.59 — Anattalakkhaṇa Sutta
- SN 35.28 — Ādittapariyāya Sutta
- AN 3.65 — Kesamutti Sutta
- Khp 5 — Maṅgala Sutta
- Khp 6 — Ratana Sutta
- Khp 9 — Karaṇīyamettā Sutta
- Dhammapada 1 — Yamakavagga
- Dhammapada 183 — Buddhāna Sāsana
- Udāna 1.10 — Bāhiya Sutta
- DN 16 — Mahāparinibbāna Sutta

The dataset is deliberately marked as a starter corpus. Before a future public release claims a particular printed or online edition, its provenance, transcription rights, and translation license must be independently verified.
