# Citation Engine

Every public paragraph should expose:

- stable ID
- work title
- section/paragraph number
- edition
- source
- URL fragment

Supported copy formats:

- plain text
- Markdown
- HTML
- BibTeX where meaningful

Example:

```text
MN 10, mn10.p002, DEMO-EDITION-001
https://example.org/read/mn10/#mn10.p002
```

The production URL must be generated from configuration rather than hard-coded into data.
